Comparador

Tres direcciones para el sistema visual de Mapa Inestable

Mismo contenido en las tres: el home con un análisis featured de Colombia y una grilla de cuatro países más. Lo que cambia es el tratamiento — color, tipografía, densidad, jerarquía, voz visual. Cada una toma una decisión distinta sobre cuánto del logo trasladar al sistema y qué tradición editorial reclamar.

Dirección A

Editorial denso latinoamericano

Anfibia · Crisis · La Agenda · Le Monde Diplomatique

Doblemente latinoamericano: la materia (papel crema, terracota, verde oliva) y el formato (revista política impresa, grilla densa, dropcap, italianas para citas). El logo opera como cabecera de revista, no como brand.

Tipografía

Spectral 700/800 para títulos
Spectral 400 para body
IBM Plex Sans para metadata

Tono

Denso, materialista, crítico. Le habla a alguien que ya leía Crisis en 1974.

Riesgo

Puede leerse como demasiado de izquierda académica — generacional. Cierra audiencias.

Dirección B

Grabado / Taller de Gráfica Popular

Antonio Berni · TGP · Torres García · panfletos políticos del cono sur

Doblar la apuesta del logo. Toda la pantalla es terracota impresa. La identidad sale del marco del avatar y se vuelve interfaz. Aesthetic manifiesto: bordes gruesos, sombras duras, tipografía slab/tallada. Riesgo alto, recompensa alta.

Tipografía

Alfa Slab One para display
Fraunces SOFT axis para titulares
Lora para body
IBM Plex Mono para metadata

Tono

Materialidad, oficio, política como producción gráfica. Reclama una tradición que el logo ya invoca.

Tokens

Riesgo

Cansa en sesiones largas. El terracota dominante es fuerte. Puede leerse como folk si no se calibra.

Dirección C

Sobrio editorial latino

Granta · The Dial · n+1 · La Pública · Revista Otra Parte

El contenido es protagonista. El logo y los colores existen pero no compiten. Aire generoso, tipografía clásica con ADN latino (Cormorant), terracota y verde solo como puntos de tensión. Lectura serena, ensayística. La promesa: esto se puede leer 30 minutos.

Tipografía

Cormorant Garamond para títulos
Crimson Pro para body
IBM Plex Sans small caps para UI

Tono

Pensativo, ensayístico. Le habla a alguien que también lee el FT y la LRB.

Tokens

Riesgo

Puede ser indistinguible de cualquier sitio editorial premium. La marca pierde diferenciación.
