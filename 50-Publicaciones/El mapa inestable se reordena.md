# El mapa inestable se reordena

> *Atraparon al Mencho. Antes de opinar, ordenemos las categorías.*

## Tesis principal

Frente a un evento de gran impacto, el método del proyecto no es interpretarlo de inmediato sino **mostrar el mapa con el cual se interpretaría**. El hecho importa, pero importa más el marco en el que se inscribe. Sin categorías compartidas, cada noticia se vuelve episodio aislado. **Si todo es episodio, nada es proceso.**
